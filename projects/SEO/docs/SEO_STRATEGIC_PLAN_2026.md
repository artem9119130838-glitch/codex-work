## 3. Регламент создания B2B-контента без копирайтера

```
[Артем: Первоисточник]
   ├── Голосовое сообщение / тезисы реальной сделки
   ├── Нюансы переговоров с китайским заводом (WeChat, торги, спецификации)
   └── Реальная проблема клиента (115-ФЗ, отказ Ozon в карточке, брак партии)
          │
          ▼
[Antigravity AI: Цифровой B2B-редактор]
   ├── Выжимка фактуры, очистка от шума и «воды»
   ├── Натяжка на жесткую B2B-структуру (Проблема → Разбор рисков → Схема решения → Расчет)
   ├── Внедрение поисковой семантики (LSI-ключи, H2/H3, FAQSchema)
   └── Органичная перелинковка на хабы Оборудования и Проверки поставщика
          │
          ▼
[Артем: Апрув за 2 минуты] ──(Одобрено)──► [Публикация в WordPress через WP REST API]
```

### Преимущества подхода:
1. **Нулевой риск «воды»:** Статьи содержат реальные цифры, коды ТН ВЭД, китайские реалии и термины, которые не знает ни один биржевой копирайтер.
2. **Авторский голос Long Wang:** Контент звучит убедительно для директоров производств и селлеров с оборотом от 10 млн руб.
3. **Экономия времени Артема:** 3 минуты на диктовку голосом вместо многочасового написания текстов.

### 3.1. Вечные правила контура для экспертных статей (Strict Editorial Invariants):
1. **Защита кликабельности в ИИ-выдаче (AI Snippet Guard & noindex/max-snippet):**
   * В мета-тегах статьи обязательно задается `<meta name="robots" content="max-snippet:150, max-image-preview:large, max-video-preview:-1">`, а для калькуляций и глубоких списков — атрибут `data-nosnippet`. Поисковые нейросети (Яндекс Нейро, Google AI Overviews) обязаны отдавать пользователю краткий ответ с активной ссылкой на сайт Longwang, а не заменять статью нулевым кликом.
2. **Объем материала (Volume Guard):**
   * Объем экспертной статьи в блог — **строго не менее 1600 слов** полезного фактоидного текста.
3. **Трехуровневое ядро (1-, 2-, 3-словники с точными вхождениями):**
   * Обязательное присутствие в ядре и тексте точных форм: однословных (импорт, пошлины), двухсловных (пошлины еэк, белый импорт) и трехсловных запросов (повышение ввозных пошлин, оборудование из китая) с контролем плотности до 3–4%.
4. **Контекстная внутренняя перелинковка (Relative Links Guard):**
   * Не менее **4–6 относительных ссылок** на смежные коммерческие хабы (`/supplies-services-china/...`) и кейсы (`/projects/...`).
5. **Сдержанный академический стиль (Zero Marketing Cliches):**
   * Полный запрет кричащих маркеров («шок», «внимание», «только у нас»). Подача в выверенном, сдержанном экспертном B2B-тоне без дешевых клише.

## 4. Регламент глубокого аудита доноров внешних ссылок

Запрещено слепо доверять рейтингам бирж (GoGetLinks, Miralinks). Каждый кандидат на покупку ссылки проходит 5-этапный скоринг:

1. **Проверка реального поискового трафика (не боты):**
   * Данные счетчиков (LiveInternet, Яндекс Метрика, SimilarWeb).
   * Доля поискового органического трафика должна быть **не менее 60%** (отсекаем накрутчиков).
2. **Проверка хостинга и подсети (PBN & Neighbors):**
   * Проверка IP-адреса и ASN сервера через Whois / Reverse IP Lookup.
   * Отсутствие в соседях по серверу сеток сателлитов, казино, адалта и микрозаймов.
3. **Аудит исходящего ссылочного профиля:**
   * Парсинг последних 20 статей донора.
   * Если донор продает ссылки на онлайн-игры, казино, крипту или сомнительные сервисы — **мгновенный отказ**.
4. **Динамика индексации в Яндексе и Google:**
   * Отсутствие резких просадок страниц в индексе за последние 6 месяцев (индикатор фильтров).
5. **Тематическая релевантность:**
   * Отраслевые медиа: электроника, машиностроение, промышленность, ВЭД, логистика, бизнес-порталы.

3. Практика таможенных брокеров (новые пошлины, ужесточение досмотров на границах ЕАЭС).

* **Запрет поисковых масок:** Радар трендов (`trend_spike_radar.py`) собирает РЕАЛЬНЫЕ взрывные поисковые всплески Google Trends по всей России без применения каких-либо ключевых масок или искусственных списков слов.

* **Секторная раскладка ИИ:** Модель (Primary: DeepSeek-V3 под контролем Hard Token Guard на 15 000 токенов, Fallback: Gemini Flash) раскладывает объективные запросы по 6 отраслевым секторам без навязывания выдуманных связей с бизнесом.
* **Автономное расписание:** Ежедневный запуск на сервере VPS в 08:30 МСК (`30 5 * * *` UTC) с доставкой дайджеста в задачу Битрикс24 №4972.

### 5.2. Инвариант проверки доноров бирж (GoGetLinks Live Verification Guard)
* **Запрет слепого доверия биржам:** Категорически запрещено оформлять заявки на размещение ссылок на GoGetLinks, Miralinks и других биржах, опираясь исключительно на внутренние метрики площадок (траст, видимость, ИКС биржи).
* **Обязательный аппаратный аудит перед заказом:** Для каждого кандидата в доноры выполняется обязательный парсинг последних 5–10 опубликованных статей через автоматический скрипт:
  1. **Проверка на ссылочный спам:** поиск ссылок на онлайн-казино, гемблинг, криптобиржи, адалт и агрессивный арбитраж трафика. Наличие даже одной спам-ссылки — немедленная дисквалификация донора.
  2. **Проверка индексации и мета-тегов:** отсутствие `noindex`, `nofollow`, атрибутов `rel="sponsored"` или закрытия раздела статей в `robots.txt`.

## 13. Регламент безопасного внедрения интерактивных виджетов и калькуляторов (Frontend & WPCode Invariant)

1. **Scoped CSS & DOM Isolation (Изоляция стилей и разметки):**
   - Все интерактивные виджеты (B2B-калькулятор оборудования, формы расчета, таблицы сравнения) обязаны иметь уникальный корневой контейнер (`#lw-calculator-widget`).
   - Категорически запрещено переопределять глобальные селекторы темы (`body`, `p`, `h2`, `input`, `button`, `form`). Стили обязаны быть изолированы внутри корня.
2. **Page-Scoped Execution (Строгая привязка к URL):**
   - Код виджета обязан содержать предикат изоляции: `if (!window.location.pathname.includes('/equipment-from-china/')) return;`.
   - На всех остальных страницах сайта виджет не должен выполнять расчеты и создавать элементы в DOM (0 байт лишнего DOM).
3. **Регламент вставки в WPCode Lite (Сниппет HTML vs JavaScript):**
   - При выборе типа кода «Сниппет JavaScript» плагин автоматически оборачивает код в `<script type="text/javascript">`. Вставка внутренних тегов `<script>` внутри такого сниппета запрещена (вызывает `SyntaxError: Unexpected token '<'`).
   - Для сниппетов, содержащих HTML-разметку или комплексный код, строго выбирать тип **«Сниппет HTML»**.
4. **Dual Readiness Check (Обход гонки событий в подвале):**
   - При размещении кода в «Сквозном подвале» (Footer) событие `DOMContentLoaded` может быть уже завершено на момент старта скрипта.
   - Обязателен двухфазный запуск:
     ```javascript
     if (document.readyState === 'loading') {
         document.addEventListener('DOMContentLoaded', initWidget);
     } else {
         initWidget();
     }
     ```
5. **Обязательный сброс кэша (WP-Optimize / Beget Nginx Cache):**
   - Любое обновление или публикация сниппета в WPCode требует немедленной очистки статического кэша страниц (в панели WordPress: *WP-Optimize ➔ Очистить кэш*), иначе посетителям и неавторизованным пользователям продолжает отдаваться старый gzip-снимок HTML.
6. **Russian VAT 22% Invariant (Ставка НДС 22%):**
   - Во всех расчетах калькуляторов растаможки, доставки оборудования и КП ставка НДС в РФ с 01.01.2026 составляет **СТРОГО 22%** (не 20%!).
