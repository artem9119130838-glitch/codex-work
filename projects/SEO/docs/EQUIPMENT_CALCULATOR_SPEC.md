> **Целевая страница:** `https://longwang.ru/supplies-services-china/equipment-from-china/`  
> **Статус:** Разработано и верифицировано в режиме `--dry-run`  
> **Связанный скрипт деплоя:** `projects/SEO/scripts/deploy_equipment_calculator.py`  
> **Файл виджета:** `projects/SEO/widgets/equipment_calculator.html`

## 1. Бизнес-цели и поведенческие факторы (SEO 2026)

1. **Максимизация времени на странице (Dwell Time):**  
   Интерактивный пересчет параметров задерживает пользователя на хабе оборудования на 2.5–4 минуты, что дает максимальный буст ранжирования коммерческих факторов в Яндексе.
2. **Контраст с "серым" карго:**  
   Наглядное выделение суммы **возврата НДС 20% к вычету** и официального **номера ГТД** для бухгалтерии и маркетплейсов.
3. **Лидогенерация горячего спроса:**  
   B2B-клиенты, рассчитывающие станки за 1–10 млн рублей, получают готовую кнопку: *«Получить расчет с кодом ТН ВЭД и спецификацией (PDF)»*, отправляющую лид прямо в Битрикс24.

## 2. Математическая модель расчета белой себестоимости

| Статья затрат | База расчета | Формула |
|---|---|---|
| **Стоимость на фабрике** | Инвойс EXW/FOB в CNY или USD | $P_{rub} = P_{cny} \times 13.55$ (или $P_{usd} \times 96.80$) |
| **Международная логистика** | Вес ($M$, кг) и Объем ($V$, $м^3$) | $L_{rub} = \max(M \times 1.25\$, V \times 230\$, 800\$) \times 96.80 \times K_{city}$ |
| **Таможенная стоимость (ТС)** | База для начисления пошлин ФТС | $TC = P_{rub} + (L_{rub} \times 0.70)$ *(логистика до границы)* |
| **Ввозная таможенная пошлина** | Ставка ЕТТ ЕАЭС (0% / 5% / 8%) | $Duty = TC \times Rate_{duty}$ |
| **Ввозной НДС 20%** | База начисления НДС | $VAT = (TC + Duty) \times 20\%$ *(к налоговому вычету!)* |
| **Таможенный сбор ФТС** | Шкала стоимости декларации | $1\,064$ – $30\,000$ ₽ в зависимости от $TC$ |
| **Сертификация ТР ТС 010/020** | Декларирование промышленной безопасности | Фиксированная индикативная оценка ~ $35\,000$ ₽ |
| **Комиссия Long Wang (3%)** | Комплексный контракт под ключ | $\max(P_{rub} \times 0.03, 45\,000 \text{ ₽})$ |

$$\mathbf{ИТОГО} = P_{rub} + L_{rub} + Duty + VAT + CustomsFee + Cert + Agency$$

## 4. Архитектура интеграции с WordPress и CRM

1. **Фронтенд виджета:** Чистый Vanilla JS без внешних тяжелых зависимостей (jQuery/React), мгновенный пересчет в реальном времени (`input` + `change`), валидация полей, модальное окно.
2. **REST API захвата лида:** AJAX POST-запрос на `/wp-json/longwang/v1/calc-lead` с передачей параметров:
   * Имя, Телефон, Email, ИНН компании;
   * Выбранное оборудование, валюта, инвойс, вес, объем;
   * Рассчитанная итоговая сумма и сумма вычета НДС.
3. **CRM воронка Битрикс24:**
   * Создание лида/сделки в воронке «Оборудование / Снабжение»;
   * Автоматическое прикрепление источника `equipment_calculator_hub`;
   * Задача руководителю направления снабжения оборудования.
