# Проект: Личная организация и автоматизация порядка (Personal Organization)

## 1. Назначение
Проект объединяет регламенты, стандарты хранения файлов контура, шаблоны поставок и инструменты автоматического наведения порядка на рабочем столе и в рабочих директориях ПК (`C:\Codex_Personal`, `D:\Документы Sync E`).

## 2. Структура проекта
```text
projects/personal_organization/
├── README.md                      ← Текущее описание проекта
├── ORGANIZATION_RULES.md          ← Единые правила хранения, вложенности и шаблонов
└── skills/
    └── desktop_and_folder_cleanup.md ← Локальная копия навыка ассистента
```

Связанные инструменты в репозитории:
* `scripts/organize_desktop.py` — основной исполняемый скрипт двухэтапного наведения порядка (`--dry-run` и `--execute`).
* `SKILLS.md` — глобальный индекс навыков ИИ (навык №12).
* `C:\Users\Artem\.gemini\config\skills\desktop_and_folder_cleanup\SKILL.md` — глобальная конфигурация навыка для Gemini/Antigravity.

## 3. Регламент вызова
При получении команды от пользователя:
> *"Наведи порядок на рабочем столе"* или *"Наведи порядок в папке <путь>"*

Ассистент обязан:
1. Запустить скрипт в режиме предварительного аудита:
   ```powershell
   py scripts/organize_desktop.py --dry-run
   ```
2. Провести экспертную валидацию карты перемещений по правилам `ORGANIZATION_RULES.md`.
3. Запустить боевой перенос:
   ```powershell
   py scripts/organize_desktop.py --execute
   ```
4. Убедиться в формировании на рабочем столе файла `ПАМЯТКА_ГДЕ_МОИ_ФАЙЛЫ.txt`.
