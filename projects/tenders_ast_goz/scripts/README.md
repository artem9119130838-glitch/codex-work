# Модуль автовыгрузки документации АСТ ГОЗ (Air-Gap Automation)

Модуль содержит готовые инструменты для автоматизированного скачивания пакетов тендерной документации с площадки `223.astgoz.ru` в условиях изолированного контура (без публичного интернета).

Подробное техническое задание и ретроспектива:
См. [docs/mikhail_task_ast_goz_automation.md](../../docs/mikhail_task_ast_goz_automation.md).

План и методика тестирования модуля на ГОЗ-станции:
См. [scripts/ast_goz/test_plan.md](test_plan.md).

Понятная инструкция для тендерного менеджера (Александры):
См. [scripts/ast_goz/instruction_for_aleksandra.md](instruction_for_aleksandra.md).

## 1. Вариант А: Playwright over CDP (Рекомендуемый стандарт)

Файл: `playwright_cdp_downloader.py`

### Требования:
* Python 3.10+
* `pip install playwright` (установить заранее ДО включения ViPNet VPN / сетевой изоляции).
  > **Важно:** Запускать `playwright install` (скачивать встроенные браузеры Playwright) **НЕ ТРЕБУЕТСЯ**, так как скрипт подключается через CDP напрямую к уже установленному на компьютере Chromium-ГОСТ/Яндекс.Браузеру с КриптоПро.
* Браузер с поддержкой ГОСТ-криптографии (Chromium-ГОСТ, Яндекс.Браузер, Google Chrome).

### Быстрый запуск (через батник):
Дважды кликните `run_astgoz_chromium.bat` (или `run_astgoz_cdp.bat`) в папке `scripts/ast_goz/`. Скрипт сам запустит браузер с портом 9222, подождет пока вы вставите токен и войдете в реестр, а затем запустит робота.

### Ручной порядок запуска:
1. Запустите браузер с портом отладки DevTools:
   ```cmd
   chrome.exe --remote-debugging-port=9222 --user-data-dir="C:\astgoz_browser_profile"
   ```
2. Вставьте аппаратный токен ЭЦП (Рутокен) и выполните вход в личный кабинет АСТ ГОЗ.
3. Откройте реестр лотов: `https://223.astgoz.ru/registry/view/pr_lots_all` и выставьте нужные фильтры (например, галку «Интересно»).
4. Запустите скрипт:
   ```cmd
   python playwright_cdp_downloader.py --output-dir="C:/AST_GOZ_DOCS" --max-lots=30
   ```
5. Скрипт обработает строки таблицы, скачает архивы и сложит их в папку: `C:\AST_GOZ_DOCS\<НомерПроцедуры>\<НомерПроцедуры>.zip`.
   * **Дедупликация:** если архив лота уже скачан и не пустой, он пропускается.
   * **Сохранность реестра:** обработка ведется в одноразовых вкладках, страница реестра никогда не перезагружается и не теряет фильтры.
   * **Статусная метка:** после скачивания автоматически вызывается метка `action=set_documents` («Подготовить документы») и обновляются фильтры реестра.

## 2. Решения для Mozilla Firefox

Если на рабочей станции АСТ ГОЗ настроен именно **Mozilla Firefox** (с плагином КриптоПро и сертификатами):

### Вариант 1 (Идеально для Firefox): Tampermonkey Userscript (Master-Worker 4.0)
Файл: `astgoz_master_worker.user.js` («AST-GOZ CONTROL 4.0»)

Это самый надежный и простой способ автоматизации для Firefox, не требующий установки Python, драйверов и открытия сетевых портов.
* **Как установить:** Откройте Tampermonkey в Firefox -> «Создать новый скрипт» -> вставьте содержимое файла `scripts/ast_goz/astgoz_master_worker.user.js` -> Сохранить (`Ctrl+S`).
* **Как работает:**
  1. Вы заходите в личный кабинет АСТ ГОЗ, открываете реестр лотов: `https://223.astgoz.ru/registry/view/pr_lots_all`.
  2. В правом верхнем углу страницы появляется панель управления: **🦊 AST-GOZ CONTROL 4.0**.
  3. Нажимаете зеленую кнопку: **`🚀 ПОЛНЫЙ АВТОМАТ (Master-Worker)`**.
  4. Вкладка реестра **никогда не перезагружается и не уходит со страницы** (полный отказ от ненадежных `history.go(-2)` и `history.back()`).
  5. Каждый лот открывается во временной фоновой вкладке через `GM_openInTab`, подписывается ЭЦП, инициирует выгрузку архива и автоматически закрывается через `window.close()`.
  6. На вкладке реестра безопасно вызывается метка «Подготовить документы» и в конце автоматически нажимается «Применить фильтры».
* **Настройка Firefox перед запуском:**
  В `Настройки Firefox` -> `Основные` -> `Файлы и приложения` выберите **«Всегда сохранять файлы в папку Загрузки»** (чтобы браузер не показывал окно подтверждения пути для каждого ZIP).

---

### Быстрый запуск для Firefox (через батник):
Дважды кликните `run_astgoz_firefox.bat` в папке `scripts/ast_goz/`. Батник предложит на выбор:
- **Вариант [1]:** Запустить Firefox для работы с расширением Tampermonkey (рекомендуется);
- **Вариант [2]:** Запустить Firefox с флагом `-marionette` и запустить Python-робота.

---

### Вариант 2: Внешний Python через Marionette
Файл: `firefox_marionette_downloader.py`

Применяется, если выгрузку в Firefox требуется вызывать внешним Python-процессом.
* Требования: `pip install selenium`, `geckodriver.exe`
* Ручной запуск Firefox:
  ```cmd
  "C:\Program Files\Mozilla Firefox\firefox.exe" -marionette -start-debugger-server 2828
  ```
* Запуск скрипта:
  ```cmd
  python firefox_marionette_downloader.py
  ```
