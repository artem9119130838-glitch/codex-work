## 1. Диагностика и локализация инцидента

### 1.1. Симптом и текст ошибки
При попытке открыть карточку лида **ООО «РСО-ЭНЕРГО»** (ИНН `3661054875`) в пользовательском интерфейсе 1С:УНФ возникало модальное окно аварийного завершения:
```text
{ОбщийМодуль.ТегированиеОбъектов.Модуль(285)}: Преобразование значения к типу Число не может быть выполнено
```

### 1.2. Стек вызовов платформы 1С:
```text
1. Справочник.Лиды.Форма.ФормаЭлемента.Форма (строка 194): ПриСозданииПриЧтенииНаСервере();
2. Справочник.Лиды.Форма.ФормаЭлемента.Форма (строка 3500): ТегированиеОбъектов.ПриСозданииПриЧтенииНаСервере(ЭтотОбъект,Объект);
3. ОбщийМодуль.ТегированиеОбъектов.Модуль (строка 13): ПрочитатьДанныеТегов(Форма, Объект);
4. ОбщийМодуль.ТегированиеОбъектов.Модуль (строка 181): НовыеДанныеТега.ПредставлениеТега = ФорматированнаяСтрокаПредставленияТега(Выборка.Наименование, Выборка.ПометкаУдаления, НавигационнаяСсылкаФС);
5. ОбщийМодуль.ТегированиеОбъектов.Модуль (строка 285): КомпонентыФС.Добавить(Новый ФорматированнаяСтрока(НаименованиеТега + Символы.НПП, Шрифт, Цвет));
```

### 1.3. Первопричина (Root Cause)
1. В табличной части `Теги` справочника `Catalog_Лиды` у лида `ООО «РСО-ЭНЕРГО»` был записан GUID:
   `7e8d7ab6-df13-11ef-9922-02006df8aab5`.
2. Запрос к OData `Catalog_Теги(guid'7e8d7ab6-df13-11ef-9922-02006df8aab5')` возвращал **HTTP 404 Not Found** («Экземпляр сущности не найден»).
3. В базе 1С:УНФ эталонный тег **«Крупный»** имеет GUID:
   `7e8d7ab8-df13-11ef-9922-02006df8aab5` (окончание на цифру **`8`**, а не **`6`**).
4. В типовом общем модуле 1С:УНФ `ТегированиеОбъектов` при обработке битой ссылки свойства тега (`Наименование`, `ПометкаУдаления`) возвращаются пустыми/неопределенными, из-за чего вычисление цвета оформления тега падает на строке 285 с ошибкой приведения типов, полностью блокируя открытие формы элемента.

## 3. Выполненные исправления в 1С:УНФ

1. Разработан и согласован в режиме `--dry-run` план исправления для всех 5 записей.
2. Произведено боевое обновление через OData PATCH:
   - Невалидный GUID `7e8d7ab6-df13-11ef-9922-02006df8aab5` заменен на канонический `7e8d7ab8-df13-11ef-9922-02006df8aab5` («Крупный»).
   - Сохранены все остальные привязанные теги без потерь.
   - Нормализована нумерация строк `LineNumber`.
3. **Контрольный аудит:** Повторное сканирование всех 1259 лидов с тегами показало: **0 дефектов**. Карточка `ООО «РСО-ЭНЕРГО»` и остальные 4 карточки открываются штатно без ошибок.
