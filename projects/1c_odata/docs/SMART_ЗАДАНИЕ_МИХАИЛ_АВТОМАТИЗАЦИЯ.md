## 📐 1. ПАСПОРТ ЗАДАЧИ ПО СТАНДАРТУ SMART

* **S (Specific — Конкретность):** Довести полуавтоматический DOM-скрипт Tampermonkey в браузере Firefox на изолированной машине АСТ ГОЗ до стабильного пакетного скачивания архивов документации по поисковой выдаче и настроить разделение результатов парсера Фазы 2 на 3 жестких потока (корзины).
* **M (Measurable — Измеримость):**
  1. Пакетный скачиватель выгружает от 30 до 50 архивов за одну поисковую сессию без ручного клика по каждой закупке.
  2. Воркер Фазы 2 автоматически распределяет 100% поступивших архивов по трем вкладкам итогового отчета:
     - «ЗЕЛЕНАЯ КОРЗИНА»: Товары без СМР, без Нацрежима, **АВАНС $\ge 30\%$**, НМЦК от 500к до 2 млн руб.
     - «ЖЕЛТАЯ КОРЗИНА»: Товары без СМР и запретов, но БЕЗ аванса (0–20%).
     - «КРАСНАЯ КОРЗИНА»: Отсеянные закупки с указанием точной причины (ПП 616/1875, услуги/СМР, сумма <500к или >2 млн).
* **A (Achievable — Достижимость):** Базовый скрипт Tampermonkey и видеозапись процесса уже переданы Артёмом, код воркера и интеграция n8n/DeepSeek уже развернуты.
* **R (Relevant — Релевантность):** Снимает 6 часов ежедневной механической рутины с Александры и обеспечивает непрерывный поток спецификаций для трех закупщиц в Китае.
* **T (Time-bound — Ограниченность во времени):**
  - Калибровка скрипта Tampermonkey совместно с Александрой: **в течение 24 часов**.
  - Прогон контрольного пакета из 30 архивов через 3 корзины: **в течение 48 часов**.

## 💻 2. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ К РЕАЛИЗАЦИИ

### Блок А. Пакетный скачиватель АСТ ГОЗ (Tampermonkey):
1. **Среда исполнения:** Изолированная рабочая машина АСТ ГОЗ (Firefox + ViPNet Client). Внешней сети нет.
2. **Логика работы:**
   - Скрипт перебирает строки таблицы извещений в результатах поиска;
   - Автоматически нажимает кнопку перехода в документацию и триггерит скачивание ZIP-архива;
   - Складывает файлы в локальную папку `C:\AST_GOZ_INBOX\`;
   - Добавляет рандомную задержку между кликами (1.5–3.0 сек) для предотвращения блокировок сессии на ЭТП.

### Блок Б. Пре-фильтр Фазы 2 (3 Корзины):
1. **Обработка входных архивов:** Архивы из локальной папки загружаются в Google Диск / воркер.
2. **Правила маршрутизации:**
   - **Корзина 1 (Авто-старт):** Товар + Аванс $\ge 30\%$ + Срок $\ge 7$ дней + НМЦК 500к–2М $\to$ формируется строка со спецификацией для CRM и снабжения.
   - **Корзина 2 (Ручной добор):** Чистый товар, но без аванса $\to$ статус `MANUAL_REVIEW` для Александры.
   - **Корзина 3 (Отсев):** СМР, монтаж, услуги, жесткий нацрежим без эквивалента $\to$ статус `REJECT` с фиксацией цитаты из ТЗ.
