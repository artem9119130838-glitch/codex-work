## 第二部分 / ЧАСТЬ II. 供应商管理与价格底线 / РАБОТА С ФАБРИКАМИ

> **核心原则 / Главное правило:**  
> “你不是1688的链接搬运工，你是中国最低工厂价格的挖掘者。”  
> *«Ты — не почтальон ссылок с 1688. Ты — добытчик лучшей цены в Китае».*

### 📜 守则要点 / Заповеди:
1. **直达实体工厂 / Поиск реального производителя:**  
   寻找真正的源头工厂，而不是1688或贸易商中间商。贸易商吃掉我们20%–30%的利润空间，会导致我们投标失利。要求工厂提供车间照片或视频。
2. **坚决砍价 (-10% 至 -15%) / Обязательный торг:**  
   如果你的报价与1688公开标价一致，则你的工作价值为零。你必须争取到底价——至少比公开市场价**低10%–15%**。
3. **精准核实重量与包装尺寸 / Точный вес и габариты (Урок сепаратора):**  
   严禁凭感觉估算重量。在向俄罗斯发送最终报价前，必须要求工厂提供木箱包装的精确长×宽×高（箱规）及毛重（Gross Weight）。重量误差会导致国际物流运费翻倍，吞噬所有利润。
4. **工厂铭牌拍照核实 / Фото заводского шильдика:**  
   电机、泵类、电气设备必须核实电压、转速、功率和防爆等级。必须索取工厂实物铭牌（Nameplate）照片，杜绝臆测。
5. **合规发票 (13% 专票) / Чистые счета с НДС 13%:**  
   明确要求正规白关出口及13%增值税专用发票（专票）。严禁无票散货。

## 第四部分 / ЧАСТЬ IV. 采购员情景考核考题 / СИТУАЦИОННЫЙ ЭКЗАМЕН (5 КЕЙСОВ)

*(每位采购员必须在入职考核中书面回答以下5道实际业务情景题 / Сотрудницы письменно отвечают на 5 кейсов):*

* **情景题 1 / Кейс 1 (砍价能力):**  
  你在1688上找到了一台泵，公开标价为 12,000 元。工厂客服说不能降价。你的正确行动是什么？  
  *标准答案:* 电话联系工厂销售经理，核实是否为源头实体厂家，索要工厂车间视频，争取批量采购底价（争取下浮10%–15%至10,200–10,800元），并确认13%增值税专票。
* **情景题 2 / Кейс 2 (重量与物流):**  
  俄罗斯询价单要求一台电机。工厂在聊天中说“大概50公斤左右”。你可以直接将50公斤报给俄罗斯吗？为什么？  
  *标准答案:* 绝对不可以！必须要求工厂提供正式木箱包装规格（长×宽×高，米）以及精确过磅毛重（Gross Weight）。少报重量会导致运费巨额亏损。
* **情景题 3 / Кейс 3 (铭牌与参数):**  
  图纸要求防爆电机（ExdIIBT4），工厂发来了一张没有防爆标志的通用电机实物照片。你的处理方式？  
  *标准答案:* 立即拒绝该样品，要求工厂提供具备合格防爆证书和铭牌标志的型号，严禁弄虚作假或抱侥幸心理。
* **情景题 4 / Кейс 4 (时效与沟通):**  
  俄罗斯内部客户亚历山德拉发来的任务截止时间是今天下午17:00，但工厂工程师在出差，明天才能出图纸。你应该怎么做？  
  *标准答案:* 严禁等到超期变红！在今天中午前在Bitrix24任务中顺延24小时，并清晰备注：“工厂总工出差，图纸明日上午提供，延期至明日17:00”，并艾特亚历山德拉。
* **情景题 5 / Кейс 5 (语言自立):**  
  俄罗斯发来了一份纯俄语的技术规格书。能否直接回复“看不懂，请翻译成中文再给我”？  
  *标准答案:* 严禁如此回复！必须自主使用DeepSeek/DeepL进行技术参数翻译；如有特定参数无法确定，整理出具体疑问清单向亚历山德拉提问。
