# Справочник и реестр скриптов проекта 1c_odata

В данном каталоге собраны все ключевые автономные инструменты интеграции 1С:УНФ, Битрикс24, DaData, Saby и почтовых серверов Hostland. Скрипты разработаны для автономной работы и возвращают компактный JSON, чтобы не расходовать токены контекста ИИ-ассистентов.

---

## 1. `scripts/check_contractor.py`
**Назначение:** Полная квалификация контрагента по ИНН (DaData + Saby).  
**Что делает:**
* Мгновенно опрашивает DaData API (название, КПП, ОГРН, статус, руководитель, ОКВЭД).
* Выполняет глубокую проверку через бесплатную веб-сессию СБИС (`online.sbis.ru/page/contractor?inn=...`) под аккаунтом `top-gk@yandex.ru`, подсчитывая точное количество торгов в роли поставщика (`participant_count`) и заказчика (`customer_count`) без использования платного API ВОК.
* Рассчитывает рекомендованные теги 1С (`Производство`, `Крупный`, `Холдинг`, `Конечный покупатель`, `Перепродажники`, `Тендер`) и выводит готовый вердикт.

**Использование:**
```bash
py scripts/check_contractor.py 7447110140
py scripts/check_contractor.py 7447110140 --json
```

## 2. `scripts/search_1c_entities.py`
**Назначение:** Быстрый сквозной поиск сущностей в базе 1С:УНФ через OData API без расхода токенов.  
**Что делает:**
* Ищет контрагентов по ИНН (`Catalog_Контрагенты`), проверяя флаги `Покупатель`, `Поставщик`, `ПрочиеОтношения`.
* Ищет лиды по ИНН (`Catalog_Лиды`).
* Ищет контактные лица (`Catalog_КонтактныеЛица`) и контакты лидов (`Catalog_КонтактыЛидов`) по email.
* Возвращает компактный структурированный JSON.

**Использование:**
```bash
py scripts/search_1c_entities.py --inn 2508001544
py scripts/search_1c_entities.py --email alexey.rauzhin@vostport.ru
```

## 3. `scripts/sync_leads_1c_bitrix.py`
**Назначение:** Канонический монолитный конвейер сквозной синхронизации лидов 1С:УНФ и Битрикс24 CRM (Zero-Blank Lead Guard).  
**Триггеры:** `«синхронизируй лидов, создай и обнови»`, `«синхронизируй лидов из почты»`.  
**Что делает:**
* Синхронизирует и обогащает Лиды (`Catalog_Лиды`), Компании (`crm.company`, поле ИНН `UF_CRM_699421CD2A684`) и Контакты (`crm.contact`).
* **Tag Integrity Guard & Repair:** Проверяет табличную часть `Теги` в 1С:УНФ, предотвращает падение формы элемента (`ТегированиеОбъектов.Модуль(285)`), автоматически исправляет опечатки GUID (`7e8d7ab6...` -> `7e8d7ab8...` `Крупный`) и отсекает удаленные/несуществующие теги.
* **Bounce & Unsubscribe Guard (`--clean-email`):** Удаляет недействительные email из карточек Б24 и 1С без удаления контактов.
* **СБИС-скоринг (`check_contractor`):** Автоматически обогащает досье контрагента по ИНН.
* **Строгий режим `--dry-run`:** Все модификации перед записью выводятся на экран.

**Использование:**
```bash
py scripts/sync_leads_1c_bitrix.py --since 2026-09-25 --limit 10 --dry-run
py scripts/sync_leads_1c_bitrix.py --audit-tags --dry-run
py scripts/sync_leads_1c_bitrix.py --fix-tags --dry-run
py scripts/sync_leads_1c_bitrix.py --fix-tags
```

## 4. `scripts/create_1c_lead.py`
**Назначение:** Автономное создание и привязка Лида в 1С:УНФ (Zero-Blank Lead Guard & Event Link Guard).  
**Что делает:**
* Фаза 1: `POST` базовых реквизитов Лида.
* Фаза 2: `PATCH` табличной части `КонтактнаяИнформация` (email, телефоны, адреса) и `Теги` с автоматической валидацией через `TAG_TYPO_MAP`.
* Фаза 3: `POST` контакта лида в `Catalog_КонтактыЛидов`.
* Фаза 4: Привязка входящего письма (`Document_Событие`) к созданному Лиду через ТЧ `Участники`.
* Фаза 5: Обязательная `GET`-валидация созданной карточки.
* Поддерживает канонические теги: `--tag-large` (`Крупный`), `--tag-production` (`Производство`), `--tag-tender` (`Тендер`), `--tag-reseller` (`Перепродажники`), `--tag-end-buyer` (`Конечный покупатель`), `--tag-holding` (`Холдинг`), `--tag-individual` (`Физик`).

**Использование:**
```bash
py scripts/create_1c_lead.py --dry-run --title "ООО «Тест»" --inn "7701234567" --tag-large --tag-tender
py scripts/create_1c_lead.py --commit --title "ООО «Тест»" --inn "7701234567" --tag-large --tag-tender
```

## 5. `scripts/deal_followup_pipeline.py`
**Назначение:** Модульный конвейер контроля сделок и напоминаний (Follow-up Pipeline).  
**Что делает:**
* Скачивает вложения КП/спецификаций из Битрикс24 Диска с сохранением исходных кириллических имен по стандарту RFC 2231.
* Генерирует черновики писем через IMAP (`sales@longwang.ru`, папка `Черновики`).
* Предотвращает спам через кулдаун (7–10 дней) и агрегацию сделок по одной компании/контакту.
* Разделяет CRM-напоминания: `CRM_TODO` (+4..5 рабочих дней) на 1–2 касания и эскалация в телефонные звонки (`TYPE_ID: 2`) при $\ge 3$ безответных касаниях.

## 6. `scripts/process_today_followup_deals.py`
**Назначение:** Главный CLI-конвейер разбора незавершенных дел и сделок на сегодня.  
**Алиасы быстрого запуска:** `«follow up deals today»`, `«ащддщ up deals today»`.  
**Что делает:**
* Выбирает из Битрикс24 все незавершенные дела (`OWNER_TYPE_ID: 2`), где крайний срок $\le$ сегодня или просрочен.
* Анализирует историю касаний по сделке: при 0–1 касании формирует персонализированный черновик в Roundcube IMAP, закрывает текущее дело и ставит `CRM_TODO` на +4..5 дней.
* При $\ge 2$ неотвеченных касаниях создает дело-звонок Артему с телефоном клиента.
* Безопасный запуск: `py scripts/process_today_followup_deals.py --dry-run`.
* Боевой запуск: `py scripts/process_today_followup_deals.py`.

## 7. `scripts/search_bitrix_knowledge.py`
**Назначение:** Канонический конвейер интеллектуального поиска знаний, задач, созвонов, чатов и протоколов в Битрикс24 по нечетким запросам.  
**Что делает:**
* Сканирует задачи Битрикс24, отсекая шум и автоматические задачи парсера тендеров (`=Проанализировать`, `=Тендер`).
* Фильтрует задачи по участникам (постановщик, ответственный, соисполнители, аудиторы) и ключевым словам в заголовках и описаниях.
* Инспектирует внутренние регламенты задач, комментарии (`task.commentitem.getlist`) и привязанные чаты (`chatId`, `im.dialog.messages.get`).
* Позволяет мгновенно находить протоколы регулярных созвонов (понедельник/пятница), результаты отбора номенклатуры и резюме BitrixGPT.

**Использование:**
```bash
py projects/1c_odata/scripts/search_bitrix_knowledge.py --query "созвон тендеры" --users 20,38
py projects/1c_odata/scripts/search_bitrix_knowledge.py --task-id 780
py projects/1c_odata/scripts/search_bitrix_knowledge.py --chat-id 1504 --limit 50
```
