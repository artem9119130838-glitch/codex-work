## 2. Как снабжению искать поставщиков в Битрикс24 (привычки 1С ⮂ CRM)

Снабженцы привыкли к интерфейсу 1С:УНФ — к дереву папок слева и поиску по коду/названию. В Битрикс24 реализованы **прямые аналоги всех привычных механизмов 1С**:

👉 **Основная рабочая область:** [Список компаний в CRM Битрикс24](https://b24-g4wfjq.bitrix24.ru/crm/company/list/)

```
                    ПРИВЫЧКА В 1С                       ➔                  КАК ЭТО СДЕЛАТЬ В БИТРИКС24
 ────────────────────────────────────────────────────────────────────────────────────────────────────────────
 1. Поиск по дереву папок («Гидравлика», «Насосы»)      ➔   Фильтр по полю «Папка 1С (Категория)»
 2. Поиск по коду 1С (например, «НФ-000853»)            ➔   Вбить код в строку общего поиска сверху
 3. Поиск по WeChat ID или номеру телефона              ➔   Поле «Мессенджер» или поиск по номеру «+86...»
 4. Поиск по специализации («Danfoss», «компрессоры»)   ➔   Поиск по слову в поле «Комментарий»
 5. Только поставщики (без клиентов и покупателей)      ➔   Фильтр «Тип компании» = «Поставщик»
```

### Подробная инструкция по настройке поиска в CRM:

1. **Поиск по категориям и папкам 1С (Главный инструмент):**
   - На странице [Списка компаний](https://b24-g4wfjq.bitrix24.ru/crm/company/list/) нажмите на строку фильтра над таблицей.
   - Если поля еще нет, нажмите шестеренку **«Настройка полей фильтра»** -> отметьте галочкой **`Папка 1С (Категория)`** -> нажмите **«Применить»**.
   - Теперь вы можете вводить название любой категории 1С: *«Насосное оборудование»*, *«Гидравлика»*, *«Лабораторное оборудование»*, *«Поставщики 1688»*, *«Аналог SMC»* — CRM покажет ровно список поставщиков из этой папки.

2. **Быстрый поиск по Коду 1С (`НФ-...`):**
   - В верхнюю поисковую строку таблицы просто введите код из 1С (например: `НФ-000853` или `НФ-001208`). Карточка фабрики найдется моментально.

3. **Поиск по китайским контактам (WeChat / WhatsApp / Email):**
   - В карточке компании заполнено штатное поле **«Мессенджер»** (`IM`) и поле **«E-mail»**. 
   - Поиск по номеру телефона (например, `136 5657 9545` или `+86...`) находит поставщика даже при частичном вводе.

4. **Поиск по специализации оборудования и аналогам брендов:**
   - Вся подробная информация из 1С (аналоги Danfoss, типы приборов, условия) перенесена в поле **«Комментарий»** карточки компании. 
   - В строке поиска CRM введите `Danfoss` или `газоанализаторы` — система найдет соответствующего производителя.

## 3. Как сопоставлять данные Битрикс24 и 1С (Сквозная связка)

Для исключения путаницы между базами 1С:УНФ и Битрикс24 реализована сквозная идентификация:

1. **Неразрывный GUID и Код 1С (`ORIGIN_ID`):**
   - Каждая синхронизированная компания в Битрикс24 хранит уникальный идентификатор из 1С (`ORIGIN_ID` = `Ref_Key` 1C, `ORIGINATOR_ID` = `1C_UNF`).
   - Даже если менеджер в Битрикс24 переименует компанию или изменит телефон, скрипт никогда не создаст дубль, а будет обновлять именно эту карточку.

2. **Защита ответственного менеджера (Safe Merge):**
   - При синхронизации скрипт **никогда не перезатирает** текущего ответственного менеджера, назначенного в CRM. 
   - Все новые поставщики из Китая по умолчанию закрепляются за ответственным по снабжению КНР — **Азатом Денишовым** (`USER_ID: 20`).

3. **Синхронизация реквизитов и банковских данных:**
   - В карточке компании в блоке **«Реквизиты»** создается юридическое лицо с указанием китайского адреса фабрики.
   - Банковские счета 1С (валютные счета, SWIFT) переносятся в банковские реквизиты Битрикс24 (`crm.requisite.bankdetail`).

4. **Закрепленная история в таймлайне:**
   - При синхронизации вверху таймлайна закрепляется карточка с иерархией папок 1С, тегами (`#1С #Поставщик #Китай #Насосное_оборудование`) и технической информацией.
