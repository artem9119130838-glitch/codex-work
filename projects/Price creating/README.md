> ⚠️ **РЕГЛАМЕНТ ДЕМАРКАЦИИ И ИЗОЛЯЦИИ КОНТЕКСТА (Deal & Domain Isolation Invariant):**

## 🛡️ Правила изоляции контекста для ИИ-ассистентов

1. **Запрет диффузии металлоизделий в общие задачи (No Custom Metal Bleed):**
   - При работе с задачами Контура 2 (сушильные шкафы, прайсы, серийное оборудование, подбор кодов ТН ВЭД) **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО** подтягивать контекст рекламаций, биения штоков, допусков H9, толщины хрома и переписки с Дэвидом по гидроцилиндрам.
2. **Запрет загрязнения сделки по гидроцилиндрам (No Generic Bleed into Deal):**
   - При работе в каталоге `Договор_62230426_Штоки_и_Трубы/` запрещено привлекать файлы и контекст прайсов сушильных шкафов и посторонних лидов.
3. **Раздельные сессии диалогов:**
   - Каждое направление ведется строго в изолированных диалогах. Запрещено смешивать обсуждение приемки партии штоков/труб с расчетами коммерческих предложений по другим товарам.
