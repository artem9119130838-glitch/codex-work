# Reactivation Templates (мягко вернуть контакт)

Общие правила:
- коротко, спокойно, без давления;
- с уважением ко времени клиента;
- дать простой “выход” (если не актуально — ок);
- цель часто не “закрыть сделку”, а сохранить канал (включить в рассылку запросов, выйти на ЛПР).

## 1) Мягкая реактивация (после долгой паузы)
Тема: Хотел уточнить по задачам с Китаем

Добрый день, [Имя].

Давно не общались, поэтому хотел аккуратно уточнить: есть ли сейчас актуальные задачи по Китаю (поставки, оплата, логистика, таможня, промышленные бренды)?

Если сейчас не актуально — ок.

С уважением,
[Имя]

## 2) Очень короткая
Тема: По задачам с Китаем

Добрый день, [Имя].

Подскажите, актуальны ли сейчас задачи по поставкам/оплатам/логистике из Китая?

Если да — можно просто прислать артикулы/ТЗ/инвойс.

С уважением,
[Имя]

## 3) С привязкой к прошлому запросу
Тема: По вашему запросу по [товар/тема]

Добрый день, [Имя].

Мы ранее общались по [товар/тема]. Хотел уточнить, закрыли ли вы тогда вопрос и есть ли сейчас похожие задачи.

Если актуально — пришлите, пожалуйста, артикулы/ТЗ/инвойс, посмотрим предметно.

С уважением,
[Имя]

## 4) После отправки КП (без ответа)
Тема: По предложению по [тема]

Добрый день, [Имя].

Проверю коротко: предложение по [тема] еще актуально?

Если да — подскажите, что сейчас важнее (цена/срок/документы/соответствие ТЗ). Скорректируем расчет и схему.

С уважением,
[Имя]

## 5) Реактивация с “закрытием касаний” (очень осторожно)
Тема: Закрываю ли вопрос по [тема]?

Добрый день, [Имя].

Похоже, по [тема] сейчас неактуально. Подскажите, пожалуйста, можно ли считать вопрос закрытым?

Если в будущем появятся заявки по Китаю/промышленным брендам, будем рады вернуться. Можно добавить нас в список поставщиков.

С уважением,
[Имя]

## 6) Реактивация по 1688/официальной схеме
Тема: По поставщику с 1688

Добрый день, [Имя].

Ранее обсуждали поставщика с 1688 и возможность поставки по более официальной схеме. Подскажите, актуально ли еще?

Если да — пришлите ссылку на поставщика и требования по документам. Сначала проверим, подходит ли поставщик по оплате/документам, и предложим следующий шаг.

С уважением,
[Имя]
