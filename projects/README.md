# Projects

Дата обновления: 2026-05-10

Эта папка хранит текущие рабочие материалы. Устойчивые знания и инструкции переносятся в `E:\Codex_Work\codex_kb`.

## Папки

- `1c_odata` - рабочие файлы 1С/OData, `default.vrd`, metadata, заметки.
- `n8n_email_ai` - n8n workflow, примеры писем, AI/RAG выгрузки.
- `n8n_bitrix` - старые и новые материалы по n8n/Bitrix.
- `tenders` - входящие, обработанные и итоговые тендерные файлы.
- `tenders_ast_goz` - AST GOZ, старый контекст и будущие рабочие файлы.
- `bitrix` - mappings и выгрузки Bitrix без секретов.
- `server_ops` - серверные логи, снимки и диагностика.
- `local_inventory` - еженедельная инвентаризация локального компьютера.

## Правило

Рабочие файлы кладем сюда. Если из рабочего файла появился устойчивый факт, переносим краткую выжимку в `codex_kb`.
