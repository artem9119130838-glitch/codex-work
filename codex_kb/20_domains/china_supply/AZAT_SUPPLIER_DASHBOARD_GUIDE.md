# Руководство руководителя: Контроль пополнения базы поставщиков и отработки задач RFQ
## Регламент для Азата Денишова по работе с аналитическим дашбордом в Metabase

---

### 1. Зачем создан этот дашборд и какую проблему он решает

Исторически в отделе снабжения возникала системная «серая зона»:
1. **Задачи закрываются «в воздухе»:** Закупщик в Китае получает задачу на поиск (RFQ), связывается с фабриками, отписывается в чате или комментариях, жмет «Завершить задачу», но **не заводит карточку завода в CRM**. В итоге компания оплатила рабочее время, а база поставщиков компании не пополнилась — наработки остаются в личных телефонах сотрудников.
2. **Имитация бурной деятельности («очковтирательство»):** Закупщик может набить за день 5–10 случайных названий компаний с 1688 без контактов, без WeChat и без понимания цен, просто чтобы «закрыть дневной план».

**Цель дашборда:** связать реальную работу по заявкам (задачи на поиск) с физическим пополнением базы качественными фабриками в CRM Битрикс24.

### 2. Как устроен дашборд в Metabase (4 рабочих блока)

Ссылка на дашборд: `http://109.248.170.181:3000/dashboard/11` (или раздел «Пополнение базы поставщиков»).

#### Блок 1. Сводные индикаторы недели (Верхняя панель KPI)
- **Новых поставщиков за неделю:** Фактическое количество добавленных карточек компаний.
- **План на отдел:** 60 компаний (расчет: 4 закупщика × 3 компании в день × 5 рабочих дней).
- **% выполнения плана:** Целевое значение — не менее 100%.
- **Задач на поиск завершено:** Объем отработанных задач за неделю.
- **Задач БЕЗ поставщика ⚠️ (Дельта / Штрафная зона):** Самый критичный показатель! Показывает количество задач, закрытых без единой привязанной компании. Должен стремиться к **0**.

#### Блок 2. Матрица по сотрудникам и дням недели (Пн–Пт)
Показывает дисциплину и ритмичность каждого сотрудника (Miss Wang, Ли Юйнань, Лиень, Цянь Ин):
- **Зеленый цвет (3 и более):** Дневная норма выполнена.
- **Желтый цвет (1–2):** Недобор нормы.
- **Красный цвет (0):** Пропуск рабочего дня.
- **Всего новых vs Задач закрыто:** Сравнение объема поиска с реальным пополнением базы.
- **Качество %:** Доля карточек со 100% заполнением (все контакты, WeChat, комментарий).

#### Блок 3. Реестр задач «Без поставщика» (Штрафная зона)
Таблица с прямыми ссылками на задачи Битрикс24, которые были закрыты со статусом «Завершена», но в поле CRM задачи нет привязки к созданной или существующей компании.

#### Блок 4. Детализация добавленных поставщиков и аудит качества
Список всех внесенных фабрик со статусами:
- `✅ 100% Заполнено` — идеальная карточка (есть название, категория, контактное лицо, WeChat, телефон/почта, подробное описание продукции и условий).
- `⚠️ Требует доработки` — карточки с пробелами (система прямо пишет, чего не хватает: «нет WeChat ⚠️», «нет комментария ⚠️», «нет контактов»).

### 3. Еженедельный чек-лист проверки (Каждую пятницу)

> [!IMPORTANT]
> **Время проверки:** Пятница, **18:30 по времени Китая (13:30 по Москве)** — сразу после окончания рабочего дня китайской команды.

1. **Шаг 1. Оценить общую цифру недели:**
   - Если отдел сделал $< 50$ компаний из 60 — неделя провалена по темпу пополнения базы.
2. **Шаг 2. Проверить Блок 3 («Задачи без поставщика»):**
   - Если счетчик $> 0$, открыть список. Каждая такая задача — это повод для прямого вопроса сотруднику: *«Задача закрыта, где контакт фабрики, у которой ты запрашивал цены?»*.
3. **Шаг 3. Проверить Блок 4 (Качество карточек):**
   - Отсортировать по статусу `⚠️ Требует доработки`.
   - Если карточка создана без WeChat или без описания завода — такая карточка **не идет в зачет бонуса**, пока закупщик ее не дозаполнит.
4. **Шаг 4. Проверить ритмичность в Блоке 2:**
   - Если сотрудник сделал 0 в понедельник и 0 во вторник, а в пятницу вбросил 15 карточек — это тревожный сигнал (аврал, поверхностный сбор данных).

### 5. Памятка: Как закупщик в Китае обязан оформлять задачу в Битрикс24

Чтобы у закупщика задача засчиталась в системе без дельты:
1. Зайти в CRM ➔ **Компании** ➔ нажать **«Создать компанию»**.
2. Ввести:
   - **Название:** Английское + Китайское название завода.
   - **Тип компании:** `Поставщик` (или `Подрядчик`).
   - **Телефон / WeChat:** Номер мобильного телефона (11 цифр) или ID WeChat.
   - **Контактное лицо:** Имя и должность менеджера фабрики.
   - **Комментарий:** Кратко суть — специализация, размер завода, условия оплаты, минимальная партия (MOQ).
3. Открыть завершаемую **Задачу на поиск** ➔ в поле **CRM** нажать **«Добавить» ➔ «Компании»** ➔ выбрать созданную карточку фабрики (`CO_...`).
4. Нажать **«Завершить задачу»**.
