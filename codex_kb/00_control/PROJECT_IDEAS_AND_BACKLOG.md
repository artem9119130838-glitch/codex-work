3. **Безопасное чтение docx на PowerShell без COM-объектов Word:**
   - Извлечение текста DOCX напрямую через `System.IO.Compression.ZipFile` и разбор внутреннего XML-файла `word/document.xml`. Это исключает зависания MS Word и ошибки COM-интерфейса в фоновых скриптах.
4. **Связывание тредов в один диалог через SMTP/IMAP заголовки:**
   - Подстановка `In-Reply-To` и `References` с ID предыдущего письма из базы `email_messages` для того, чтобы серия из 6 писем воронки склеивалась в один тред в почтовых клиентах (Яндекс Почта, Outlook, Thunderbird).

3. **Обнаружение и ликвидация скрытого спам-дефолта в коде:**

4. **Regex-санитайзер с сохранением падежей:**
   - Вместо грубой замены инфантильной фразы на фиксированное словосочетание (что приводило к несогласованным падежам вроде *«хотел деликатно поинтересоваться состоянием»* $\rightarrow$ *«хотел уточнить состоянием»*), удаляется само заискивающее наречие (*«аккуратно»*, *«деликатно»*, *«ненавязчиво»*), сохраняя правильное управление глагола.

#### 🛠 Нестандартные решения и находки:

#### 🛠 Нестандартные решения и находки:
- **Архитектура хранения истории Antigravity**:
  - Обнаружено, что список и метаданные сессий для сайдбара считываются не напрямую из SQLite `.db` файлов в `conversations/`, а из бинарного protobuf-индекса `agyhub_summaries_proto.pb`.
  - Процесс `language_server.exe` удерживает файл индекса в оперативной памяти и при любой попытке внешней перезаписи файла во время работы сбрасывает его до текущего сеанса (1.3 КБ), затирая бэкап (34 КБ).
  - Выяснено соответствие директорий запуска: флаг `--app_data_dir antigravity` указывает на работу именно с `.gemini\antigravity`, а не `.gemini\antigravity-ide`.
  - Решение: патчинг бинарных UTF-8 байтов (`Артем` / кракозябры `⥬` на `Artem`) с предварительным гарантированным `taskkill /F /IM language_server.exe` и `taskkill /F /IM Antigravity.exe`.
- **Копирование репозиториев с правами Read-Only**: При копировании объектов Git (`.git/objects/*`) в Windows стандартный `shutil.copy2` выдает `PermissionError [Errno 13]`. Добавлен обработчик со снятием атрибута только для чтения через `os.chmod(d_file, stat.S_IWRITE)`.
