# Памятка: Команды безопасного режима (Safe Mode) и экстренное восстановление графики

Этот документ содержит все ключевые команды, пояснения и инструкции, которые использовались для восстановления работоспособности ноутбука HP Victus 16.

---

## 1. Главный и самый удобный способ: Включение классического меню клавиши F8

В Windows 11 по умолчанию клавиша F8 отключена ради ускорения загрузки на SSD. Однако её можно включить одной командой навсегда.

### Как включить меню по F8 (Рекомендуемый способ):
В командной строке `cmd` от имени Администратора выполните:
```cmd
bcdedit /set {default} bootmenupolicy legacy
```

### Как этим пользоваться:
1. При включении или перезагрузке ноутбука (сразу после логотипа HP Victus) периодически нажимайте клавишу **`F8`** (или **`Fn + F8`**).
2. На экране появится классическое текстовое меню **«Дополнительные варианты загрузки»**.
3. Стрелками на клавиатуре выберите:
   * **«Безопасный режим»** — если видеодрайвер снова дал сбой и экран погас;
   * **«Обычная загрузка Windows»** — для нормальной работы.
4. Нажмите Enter.

> **Этого способа на 100% достаточно!** Если у вас включен режим F8 (`legacy`), вам больше не нужно вбивать сложные команды или рисковать застрять в Safe Mode. В любой непонятной ситуации при включении нажимаете F8 и спокойно загружаетесь в Безопасный режим.

*Если когда-нибудь захотите вернуть стандартное поведение Windows 11 без F8:*
```cmd
bcdedit /set {default} bootmenupolicy standard
```

## 2. Что такое «Принудительный режим» Безопасного режима?

### Что это значит:
«Принудительный режим» — это жесткая фиксация в загрузочной записи Windows, которая приказывает операционной системе:
> *«При каждом следующем старте и при каждой перезагрузке ВСЕГДА запускаться ТОЛЬКО в Безопасном режиме»*.

### Зачем он нужен и когда его использовать:
1. **Когда система не успевает дойти до рабочего стола:** видеодрайвер Intel или NVIDIA инициализируется на этапе экрана приветствия. Если драйвер падает или гасит экран, вы не сможете даже открыть меню Пуск. Принудительный режим гарантирует, что Windows запустится только с базовым выводом видеосигнала, минуя сбойные драйверы.
2. **Для полной очистки драйверов (DDU — Display Driver Uninstaller):** утилиты полного удаления видеодрайверов требуют запуска строго в Safe Mode, так как в обычном режиме файлы видеодрайверов заблокированы запущенными службами Windows.

### Как включить принудительный режим:
* **Вариант 1 (Через окно `msconfig`):**
  Нажмите `Win + R` ➔ введите `msconfig` ➔ вкладка **«Загрузка»** ➔ поставить галочку **«Безопасный режим»** (Минимальная) ➔ Применить.
* **Вариант 2 (Через консоль от Администратора):**
  ```cmd
  bcdedit /set {default} safeboot minimal
  ```

### ⚠️ КАК ВЫЙТИ ИЗ ПРИНУДИТЕЛЬНОГО РЕЖИМА (Обязательно знать):
Если включен принудительный режим, Windows **никогда не вернётся в обычный режим сама**, пока вы явно не отмените команду:
1. В `msconfig` во вкладке «Загрузка» **снять галочку** «Безопасный режим».
2. Либо в командной строке от Администратора выполнить:
   ```cmd
   bcdedit /deletevalue {default} safeboot
   ```

## 3. Что такое `{current}` и `{default}` и откуда берутся реальные GUID?

* **`{current}` и `{default}` — это официальные системные алиасы Microsoft:**
  Вам **НЕ НУЖНО** искать или вводить вручную длинный 36-значный буквенно-цифровой GUID вашей операционной системы.
  * **`{current}`** — зарезервированное слово, означающее *«та копия Windows, в которой вы находитесь прямо сейчас»*.
  * **`{default}`** — означает *«основная операционная система, которая грузится по умолчанию»*.
  * **`{bootmgr}`** — диспетчер загрузки Windows (управляет таймером меню).
  Windows автоматически и безошибочно понимает эти слова в фигурных скобках.

* **Когда появляется реальный GUID:**
  Реальный длинный GUID вида `{12345678-abcd-1234-abcd-1234567890ab}` создаётся только тогда, когда вы клонируете пункт загрузки:
  ```cmd
  bcdedit /copy {current} /d "Windows 11 (Безопасный режим)"
  ```
  В ответ консоль напишет:
  *«Запись успешно скопирована в {XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX}»*.
  Именно этот выданный системой уникальный GUID используется для настройки нового пункта меню:
  ```cmd
  bcdedit /set {СКОПИРОВАННЫЙ_GUID} safeboot minimal
  bcdedit /timeout 5
  ```

* **Как удалить этот созданный пункт меню навсегда:**
  1. **Способ 1 (Самый наглядный через окно `msconfig`):**
     * Нажмите `Win + R` ➔ введите `msconfig` ➔ вкладка **«Загрузка»**.
     * В списке вы увидите две системы: основную `Windows 11` и вторую `Windows 11 (Безопасный режим)`.
     * Нажмите на вторую строчку *«Windows 11 (Безопасный режим)»* и нажмите кнопку **«Удалить»** ➔ **«Применить»**.
     *(Основная Windows 11 останется нетронутой, а лишняя запись исчезнет навсегда).*
  2. **Способ 2 (Через скрипт на Рабочем столе):**
     * Запустить файл **`УДАЛИТЬ_ЛИШНЕЕ_МЕНЮ_ЗАГРУЗКИ.bat`** (или `ВКЛЮЧИТЬ_КЛАВИШУ_F8.bat`) — скрипт сам найдет GUID клонированного меню и удалит его командой `bcdedit /delete`.
  3. **Способ 3 (Через консоль от Администратора):**
     ```cmd
     bcdedit /delete {СКОПИРОВАННЫЙ_GUID}
     bcdedit /timeout 0
     ```

## 4. Экстренные действия при сбоях видеоподсистемы

* **`Win + Ctrl + Shift + B`** — мгновенный перезапуск видеодрайвера Windows без потери открытых программ (экран моргнет со звуковым сигналом).
* **`Win + P`** — переключение режима проекции экранов вслепую:
  - `Win + P` ➔ 1 раз стрелка вниз ➔ `Enter` (Дублировать экран);
  - `Win + P` ➔ 3 раза стрелка вниз ➔ `Enter` (Только второй экран — вывод напрямую на внешний HDMI от NVIDIA).
* **«Безопасный мостик» для Intel:**
  В Диспетчере устройств: на адаптере Intel ➔ *Обновить драйвер* ➔ *Выбрать из списка на компьютере* ➔ **«Базовый видеоадаптер (Майкрософт)»** ➔ *Включить устройство*. Экран работает на 1920x1080@60Hz без черного экрана.
* **Ошибка NVIDIA Код 43:**
  В Диспетчере устройств: на NVIDIA RTX 3060 ➔ *Обновить драйвер* ➔ *Выбрать из списка* ➔ обязательно выбирать пакет с суффиксом **`nvhmi.inf`** (где `i` — Intel Optimus), а не обычный `nvhm.inf`.
* **Сброс застрявших фантомных мониторов (`SIMULATED`):**
  Файл на Рабочем столе **`СБРОС_КЭША_ДИСПЛЕЕВ.bat`** (запуск от Администратора) — очищает ветки `GraphicsDrivers\Configuration`, отключает гибридный сон (`HiberbootEnabled = 0`) и баг оверлеев MPO (`DisableOverlays = 1`).

## 5. Диагностика оборудования (PowerShell)

```powershell
# Статус видеокарт (должен быть Status: OK, Problem: CM_PROB_NONE)
Get-PnpDevice -Class Display | Select-Object FriendlyName, InstanceId, Status, Problem

# Физическое подключение мониторов (Present: True / False)
Get-PnpDevice -Class Monitor | Select-Object FriendlyName, InstanceId, Status, Present

# Активные видеоконтроллеры и разрешение
Get-CimInstance Win32_VideoController | Select-Object Name, DriverVersion, Status, VideoModeDescription
```
