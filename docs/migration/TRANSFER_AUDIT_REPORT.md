## 4. Что требуется подготовить на Компьютере №2 для передачи

Для того чтобы текущий компьютер (Компьютер №1) мог беспрепятственно подключиться, забрать проект и запустить обработку лида, со второго компьютера необходимо передать следующие данные:

### Шаг 1. Точные координаты Git-репозитория
Укажите точный URL репозитория на GitHub:
```text
git@github.com:<организация-или-пользователь>/<точное-имя-репозитория>.git
```
*(Если репозиторий в личном профиле `artem9119130838-glitch`, убедитесь, что в него добавлен публичный ключ `id_ed25519` с этого ПК, либо что репозиторий доступен аккаунту).*

### Шаг 2. Пуш актуального состояния в Git
На Компьютере №2 выполните:
```bash
git status
git add .
git commit -m "feat(leads): update incoming leads sbis pipeline"
git push origin <ваша_ветка>
```

### Шаг 3. Конфигурация окружения (`.env`)
Сформируйте и передайте содержимое файла `.env` (или заполненный образец):
- **СБИС:** URL API, логин, пароль, app_client_id / app_secret (если используется СБИС API / SbisPlugin / web-автоматизация).
- **Битрикс24:** входящий вебхук или URL портала (`b24-g4wfjq.bitrix24.ru`) с правами `crm`.
- **1С:УНФ:** URL базы, учетные данные для OData/REST API для создания сделок и задач.
- **LLM/AI:** Ключи доступа Gemini / DeepSeek / OpenAI (если используются для извлечения ИНН).

### Шаг 4. Точная команда запуска
Укажите, как именно вызывается обработка:
- **CLI / Python:** 
  Пример: `py main.py --lead-id 18318 --dry-run` или `py -m app.leads_processor --lead 18318 --dry-run`
- **Или через n8n:**
