# Саммари сессии: Синхронизация рабочего контура Victus ⮂ MateBook

## 1. Суть проблемы и корень расхождения (Диагноз)

На двух компьютерах возникло расхождение из-за разницы в структуре директорий и непонимания ассистентом монорепозитория:
1. **На MateBook:**
   - Отсутствует актуальная директория `C:\Codex`.
   - Работа велась в устаревшей директории `C:\Codex_Shared`, где проекты были разрозненными подпапками (слепок от августа 2026 г.), а `1c_odata` вообще не имела Git.
   - Ассистент на MateBook видел через SSH наличие репозитория `artem9119130838-glitch/codex-work.git`, но ошибочно решил, что обработка лидов — это отдельный репозиторий с именем `leads` или `sbis`, составив ошибочный отчет о «физическом отсутствии проекта».
2. **На HP Victus:**
   - Вся рабочая среда живет в корневом монорепозитории `C:\Codex` (Git `origin/master` -> `artem9119130838-glitch/codex-work.git`).
   - Канонический скрипт обработки лидов со СБИС, DaData, 1С и Битрикс24 (`projects/1c_odata/scripts/process_b24_inbound_leads.py`) полностью работоспособен, актуален и закоммичен в Git.
   - В ходе текущей сессии на Victus успешно выполнен тест `--dry-run` по Лиду 18318: определена компания «ООО В НОВЫЙ ВЕК» (ИНН 5905024455), выполнен скоринг СБИС, отсеян мусорный файл подписи, подготовлена сделка «Honeywell» и задача Азату.

## 2. Пожелания и требования Артема к рабочему процессу

1. **Бесшовность переключения:** Артем должен иметь возможность в любой момент закрыть крышку одного ноутбука и продолжить ровно с того же места на втором ноутбуке без ручных бэкапов на внешние диски.
2. **Git как единый транспорт:** Смысл Git — моментальный обмен кодом между машинами по схеме: уходя с ПК — `git push` (или триггер «конец чата»), садясь за другой ПК — `git pull origin master`.
3. **Единая структура папок:** На обоих ПК корень проекта должен быть строго одинаковым: `C:\Codex`. Никаких оторванных веток и параллельных папок вроде `C:\Codex_Shared`.
4. **Секреты переносятся 1 раз:** Файлы `.env` не должны коммититься в Git по соображениям безопасности, но их не нужно переносить каждый день — их достаточно один раз скопировать на MateBook в целевые папки.

## 4. Пошаговый план действий на MateBook (Раз и навсегда)

Выполнить в терминале PowerShell или Git Bash на MateBook:

```bash
# 1. Перейти в корень диска C
cd C:\

# 2. Клонировать актуальный монорепозиторий как C:\Codex
git clone git@github.com:artem9119130838-glitch/codex-work.git Codex

# 3. Перейти в проект
cd C:\Codex
git checkout master
```

После этого:
1. Создать/положить перенесенный файл `.env` в папку `C:\Codex\projects\1c_odata\.env`.
2. Запустить проверку лида:
```powershell
py projects/1c_odata/scripts/process_b24_inbound_leads.py --lead-id 18318 --dry-run
```
