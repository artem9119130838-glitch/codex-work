## 🚀 АЛЬТЕРНАТИВА БЕЗ ФЛЕШЕК: Добавление Macrium в меню загрузки Windows (BCD Boot Menu)

> [!TIP]
> **Вам вообще не обязательно иметь флешку под рукой!**  
> Macrium Reflect умеет штатно встраиваться в загрузчик Windows на SSD:
> 1. В Macrium Reflect выберите меню: **`Other Tasks` ➔ `Add Recovery Boot Menu Option...`**.
> 2. Выберите **Windows PE 11 (Recommended)** и нажмите **OK**.
> 3. Macrium пропишет пункт `Macrium Reflect System Recovery` в загрузчик BCD.
> 4. В случае сбоя Windows при включении ноутбука просто выбираете этот пункт (или нажимаете `F8`), загружаетесь в среду восстановления прямо с SSD и разворачиваете образ с внешнего диска!

## ⚠️ РЕАНИМАЦИОННАЯ ФЛЕШКА: Использование JINNLIVEUSB и исправление oledlg.dll

> [!CRITICAL]
> **Образ на внешнем диске абсолютно бесполезен, если Windows упадет в «синий экран» (BSOD) или диск не загрузится!**  
> Чтобы восстановить систему из мертвого состояния, у вас должна лежать готовая аварийная флешка.

1. Вставьте любую пустую USB-флешку (достаточно 1–4 ГБ).
2. В главном меню Macrium Reflect выберите:  
   **`Other Tasks` ➔ `Create Rescue Media`**.
3. Выберите **Windows RE** (рекомендуется) или **Windows PE 11**.
4. Нажмите **Build** (Macrium автоматически запишет загрузочную среду WinRE с драйверами сети, чипсета и накопителей вашего HP Victus).
5. **Как использовать при аварии:** При включении ноутбука нажимайте клавишу **`F9`** (или `Fn + F9`) для вызова Boot Menu HP, выбирайте вашу флешку — загрузится среда Macrium для отката образа за 5 минут.

## ШАГ 1: Предварительная экспресс-проверка диска C:\

Перед созданием эталонного слепка убедитесь, что на диске C:\ нет ошибок файловой системы:
1. Запустите командную строку (cmd) от имени Администратора:
   ```cmd
   chkdsk C: /scan
   ```
   *(Параметр `/scan` проверяет диск в фоновом режиме на лету без перезагрузки ПК).*
2. Убедитесь, что вывод гласит: `Windows has scanned the file system and found no problems`.

---

## ШАГ 2: Выбор разделов для резервного копирования

> [!WARNING]
> **Типичная ошибка:** Выбрать только букву `C:`. В этом случае загрузчик UEFI и среда восстановления останутся за бортом! При восстановлении на новый SSD система просто не запустится.

1. Откройте Macrium Reflect на вкладке **`Backup`** (Создать резервную копию).
2. Найдите в списке ваш физический системный диск (Disk 1 / NVMe SSD, на котором лежит буква `C:`).
3. **Вариант А (Автоматический):** Нажмите сверху синюю ссылку:  
   👉 **`Create an image of the partition(s) required to backup and restore Windows`**  
   *(Macrium сам автоматически выделит все служебные системные разделы).*
4. **Вариант Б (Ручной контроль — убедитесь, что стоят ВСЕ галочки на системном диске):**
   - ☑ **`1 - SYSTEM / EFI System Partition`** (~100–260 МБ, FAT32) — загрузчик UEFI/BCD.
   - ☑ **`2 - MSR / Microsoft Reserved Partition`** (16 МБ).
   - ☑ **`3 - Windows (C:)`** (основной рабочий раздел).
   - ☑ **`4 - Windows RE Tools / Recovery`** (~500–1000 МБ) — среда восстановления.
5. Нажмите **`Image selected disks...`** (Создать образ выбранных дисков).

---

## ШАГ 3: Выбор места назначения (Destination)

1. В блоке **`Destination`** выберите переключатель **`Folder`** (Папка).
2. Нажмите кнопку обзора `...` и выберите ваш внешний диск (например, `E:\` или `F:\`).
3. Создайте на внешнем диске структурированную папку:  
   `E:\Macrium_Backups\HP_Victus_16\`
4. В строке **`File Name`** рекомендуется указать понятное имя шаблона:  
   `{IMAGEHASH}-Victus_Windows11_Full`

---

## ШАГ 4: Тонкая настройка параметров (Advanced Settings)

Нажмите в левом нижнем углу кнопку **`Advanced Settings`**:

### 1. Вкладка `Compression` (Сжатие):
* Выберите уровень **`High`** (Высокий).  
  *На современных процессорах Core i5/i7 12-го поколения компрессия идет со скоростью чтения SSD. Это уменьшит размер архива со 135 ГБ до **~70–80 ГБ**.*

### 2. Вкладка `File Size` (Разбивка файлов):
* Оставьте **`Automatic`** (или выберите без разбивки, если внешний диск отформатирован в NTFS / exFAT).

### 3. Вкладка `Auto Verify Image` (Контроль целостности):
* ☑ **Поставьте галочку `Verify image after backup`**!  
  *После завершения создания образа Macrium поблочно перечитает архив и сверит контрольные суммы SHA/MD5. Это 100% гарантия того, что на внешнем диске нет битых секторов и архив развернется гарантированно без ошибок.*

### 4. Вкладка `Exclusions` (Исключения):
* Убедитесь, что включены пункты:
  - ☑ **`Exclude pagefile.sys`** (исключает 16 ГБ бесполезной виртуальной памяти).
  - ☑ **`Exclude hiberfil.sys`** (исключает файл гибернации).

Нажмите **OK** для сохранения настроек.

## ШАГ 5: Запуск создания образа

1. В окне планировщика (Backup Plan Template) нажмите **`Next`** (пропуская расписание, если настраиваете разовый бэкап).
2. В окне сводки (Summary) проверьте контрольные параметры:
   - Исходные разделы: `EFI + MSR + C: + Recovery`.
   - Место назначения: Папка на внешнем диске.
   - Метод копирования: `Intelligent Sector Copy`.
   - Верификация: `Enabled`.
3. Нажмите **`Finish`**.
4. В появившемся окне оставьте галочку **`Run this backup now`** и нажмите **OK**.
5. Начнется процесс создания образа.

### Сколько займет времени:
* При скорости записи на внешний USB 3.0/Type-C SSD: **12–18 минут**.
* Размер итогового `.mrimg` файла: **~75–85 ГБ** (вместо 135 ГБ).

## ШАГ 6: Стратегия регулярности (Retention Policy)

Чтобы не забивать внешний диск дубликатами:
* **Раз в месяц** (или перед установкой крупных обновлений/экспериментов): Делать **Full Backup** (Полный образ).
* **Раз в 1–2 недели**: Выбрать существующий Full-образ в Macrium и нажать **`Differential`** (Дифференциальный).  
  *Дифференциальный образ записывает только то, что изменилось со дня создания Full-образа. Он создается за 2–3 минуты и весит всего 3–7 ГБ.*
* Старые Full-образы старше 2 месяцев можно удалять.

## 🔄 Как восстановить систему из образа (Инструкция на случай аварии)

### Ситуация 1: Windows работает, но вы хотите откатить глюк:
1. Запустите Macrium Reflect ➔ вкладка **`Restore`**.
2. Выберите ваш образ `.mrimg` на внешнем диске ➔ нажмите **`Restore Image`**.
3. Нажмите **`Copy Partitions`** ➔ **`Next`** ➔ **`Finish`**. Компьютер перезагрузится в среду WinRE и за 5 минут восстановит диск C:.

### Ситуация 2: Windows не загружается (черный/синий экран):
1. Вставьте созданную на Шаге 0 **Macrium Rescue USB** и подключите внешний диск с бэкапом.
2. Включите ноутбук и сразу нажимайте клавишу **`F9`**.
3. В Boot Menu выберите USB-накопитель.
4. Откроется интерфейс Macrium Reflect:
   - Вкладка **`Restore`** ➔ **`Browse for an image file`** ➔ укажите ваш `.mrimg` на внешнем диске.
   - Нажмите **`Restore Image`**, проверьте целевой диск и нажмите **`Next`** ➔ **`Finish`**.
5. Через **5 минут** ноутбук перезагрузится в полностью рабочую Windows 11 со всеми программами, ключами и настройками.
