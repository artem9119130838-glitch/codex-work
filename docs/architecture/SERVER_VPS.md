Этот документ содержит технические характеристики, структуру директорий и описание сервисов боевого VPS-сервера. Он предназначен для контекста ИИ-ассистента, чтобы тот мог правильно ориентироваться в системе, писать и запускать скрипты администрирования.

> [!WARNING]
> Пароли, токены и приватные ключи SSH/VPN в этот документ записывать строго запрещено.

## 2. Критичные службы (systemd)

На сервере запущены и должны оставаться активными следующие сервисы:
* `srv1cv8-8.5.1.1150.service` — Сервер 1С:Предприятие 8.3 (версия платформы `8.5.1.1150`).
* `postgrespro-std-14.service` — СУБД Postgres Pro Standard 14.
* `apache2.service` — Веб-сервер Apache (публикация баз 1С и проксирование n8n).
* `docker.service` — Контейнеры n8n, 3x-ui (VLESS Reality) и mtproto-proxy.
* `wg-quick@wg0.service` — Сервер WireGuard VPN.
* `openvpn@server.service` — Резервный сервер OpenVPN.

## 3. Размещение баз данных и путей PostgreSQL

* **Каталог данных СУБД (PGDATA):** `/var/lib/pgpro/std-14/data` (находится на быстром системном SSD `/`).
* **Базы данных в PostgreSQL:**
  * `unf` (~29 GB) — основная рабочая база 1С УНФ (находится на быстром SSD `/`).
  * `unf_restored` (~9 GB) — копия базы УНФ, перенесена на медленный `/Storage` через Tablespace `slow_disk`.
  * `buh` (~4.3 GB) — база 1С Бухгалтерия (на быстром SSD `/`).
  * `moving` (~1.7 GB) — база 1С Перемещение, перенесена на медленный `/Storage` через Tablespace `slow_disk`.
  * `money` (~182 MB) и `money_restored` (~182 MB) — базы 1С Деньги.
* **Табличные пространства (Tablespaces):**
  * Пространство `slow_disk` физически находится по пути: `/Storage/pgpro_tablespaces/slow_disk`. Используется для архивных и тестовых баз, чтобы разгрузить быстрый системный диск.
