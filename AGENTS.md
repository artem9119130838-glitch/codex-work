- **Регламент обслуживания графики и дисплеев на HP Victus 16:**
  * Порт HDMI аппаратно распаян напрямую на дискретную карту NVIDIA RTX 3060. Встроенный экран ноутбука eDP подключен к Intel Iris Xe.
  * Для видеокарты NVIDIA требуется пакет с суффиксом `nvhmi.inf` (например, `32.0.15.9649`, где «i» — Intel Optimus). Выбор стандартного `nvhm.inf` вызывает ошибку **Код 43** (`CM_PROB_FAILED_POST_START`).
  * При возникновении черного экрана на встроенной графике Intel безопасным мостиком является ручной выбор «Базовый видеоадаптер (Майкрософт)» (`basicdisplay.sys`). В этом режиме экран работает на 1920x1080@60Hz, но Windows WDDM блокирует мультимониторность и расширение рабочего стола на внешний HDMI.
  * При сбоях топологии экранов (фантомные мониторы `SIMULATED` в реестре) запускать от имени Администратора скрипт `СБРОС_КЭША_ДИСПЛЕЕВ.bat` (очистка `GraphicsDrivers\Configuration`, отключение гибридного сна `HiberbootEnabled = 0` и отключение бага MPO `DisableOverlays = 1`).
  * **Безопасный режим и загрузчик BCD на Victus:** включена классическая клавиша `F8` (`bcdedit /set {default} bootmenupolicy legacy`), таймер меню отключен (`timeout 0`) для мгновенного старта без пауз. При сбоях графики Safe Mode вызывается частым нажатием `F8` (или `Fn + F8`) при старте ноутбука. В `msconfig` запрещено пытаться удалять рабочую ОС (система защищена); удаляется только искусственная копия Safe Mode.
