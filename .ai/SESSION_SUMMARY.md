## 3. Критические ошибки и извлеченные уроки (Lessons Learned)
- **Windows Console Encoding:** При выводе иероглифов и кириллицы в консоль Windows PowerShell скрипты обязаны на старте вызывать `sys.stdout.reconfigure(encoding='utf-8')`, иначе происходит падение с `UnicodeEncodeError`.
- **REST API Bitrix24 UF_TASK_WEBDAV_FILES:** Для прикрепления файлов с Диска к задаче Битрикс24 принимает массив в формате `[f"n{file_id}"]`, а не чистые числовые идентификаторы.
- **Связка Компании в Сделке:** При обновлении сделки через `crm.deal.update` необходимо передавать `COMPANY_ID`, так как у части сделок поле компании оставалось незаполненным при наличии контакта.
- **Granular Batch Invariant:** При интерактивном пошаговом утверждении пользователем категорически запрещено плодить разрозненные скрипты под каждую сделку; монолитный скрипт с флагами `--deal-id <ID>` и `--execute` полностью решает задачу без засорения репозитория и контекста.
