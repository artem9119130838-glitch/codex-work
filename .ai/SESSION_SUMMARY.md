## 3. Критические ошибки и извлеченные уроки (Lessons Learned)
- **TypeORM Migrations в n8n**: При ручном сжатии SQLite n8n ОБЯЗАТЕЛЬНО переносить таблицу `migrations` и схему всех таблиц `execution_*` (`waitTill`, `status`, `storedAt`). Без `migrations` n8n считает базу пустой, пытается повторно создать существующие таблицы и циклически падает (`SQLITE_ERROR: table "tag_entity" already exists`).
- **Раздувание SQLite Base64 вложениями**: При обработке тяжелых PDF/ZIP в n8n обязательно отключать сохранение успешных выполнений (`EXECUTIONS_DATA_SAVE_ON_SUCCESS=none`) и ограничивать срок хранения (`EXECUTIONS_DATA_MAX_AGE=48`), иначе SQLite вырастает до 14+ ГБ и зависает по мьютексу записи.
- **Изоляция прав Docker**: Доступ к Docker равен правам root. Безопасная делегация разработчику достигается только через отдельного непривилегированного пользователя без группы `docker` со строгим whitelist скрипта деплоя в `sudoers`.
