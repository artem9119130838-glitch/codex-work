## 3. Критические ошибки и извлеченные уроки (Lessons Learned)
- **403/400 Key Quarantine Guard:** При аннулировании или утечке ключа Google API повторные попытки с этим ключом бессмысленны и приводят к падению сервиса в бесконечный цикл. Менеджер ключей обязан исключать их навсегда до рестарта.
- **Stable Model Pinning Guard:** Псевдонимы типа `gemini-flash-latest` в пиковые часы Google приводят к ошибкам 503. Использование явно зафиксированной версии `models/gemini-3.6-flash` гарантирует предсказуемую работу.
- **Парадокс интерфейса n8n (`EXECUTIONS_DATA_SAVE_ON_SUCCESS=none`):** При отключенном сохранении успешных запусков в истории отображаются только сбои. Нельзя оценивать состояние сервиса только по UI n8n без проверки логов и CRM-сущностей.
- **RabbitMQ Heartbeat:** При долгой обработке больших документов моделью Gemini брокер отключает воркер при дефолтном значении таймаута. Параметр `heartbeat` обязан составлять $\ge 600$ с.
