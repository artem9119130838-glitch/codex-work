## 3. Критические ошибки и извлеченные уроки (Lessons Learned)
- **Инцидент некликабельных файлов Б24:** Текстовые BB-коды `[DISK FILE ID=...]` не создают кликабельных ссылок в UI. Требуется триада: `UF_TASK_WEBDAV_FILES` в карточке + `im.disk.file.commit` в IM-чате + `getExternalLink` в комментариях.
- **Ложная атрибуция срывов:** Нельзя судить об ответственности по датам без фильтрации по ролям и воронкам. Сауле Бестова работала с коммерческими лидами, а не тендерами. Аудит обязан фильтровать задачи строго по `GROUP_ID == 14` (Снабжение).
- **Кросс-воронковый статус победы:** Перевод сделки из воронки «Тендеры» (Категория 24) на стадию `EXECUTING` воронки «Заказчики» (Категория 0) является победой в тендере.
- **Top-Level Pollution:** Файлы верхнего уровня (`AGENTS.md`) не должны хранить локальные регламенты. Их назначение — компактная маршрутизация к доменным манифестам.
