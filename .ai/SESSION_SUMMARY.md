## 3. Критические ошибки и извлеченные уроки (Lessons Learned)
- Необходимо учитывать расположение ИИ-компонентов и векторных баз данных в Docker при проектировании полных бэкапов системы; Конвертация окончаний строк CRLF в LF обязательна при переносе shell-скриптов с Windows на Linux; Учетные записи и приватные ключи SSH должны быть строго исключены из репозиториев Git и храниться в локальных каталогах пользователей; Ошибки с ArtifactMetadata при записи обычных файлов и вызовы grep-search без git в PATH должны пресекаться правилами
