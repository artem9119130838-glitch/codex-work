## 3. Критические ошибки и извлеченные уроки (Lessons Learned)
- **Ошибка кодировки в Python под Windows:** При выводе кириллических спецсимволов (например, полноширинной скобки `（`) в консоль Windows через стандартный `print` в Python происходит `UnicodeEncodeError`. *Урок:* Обязательно переконфигурировать стандартный вывод (`sys.stdout.reconfigure(encoding='utf-8')`) или писать логи в UTF-8 файлы.
- **Декартово произведение при FULL JOIN в 1С:** Соединение детальных таблиц (факт с регистратором, план с несколькими строками по одной статье) без полного ключа группировки приводит к размножению данных (задвоению себестоимости). *Урок:* Объединять через `UNION ALL` во временную таблицу и затем сворачивать итоговой группировкой.
- **Автозаполнение параметров дат виртуальных таблиц СКД:** СКД БСП автоматически подменяет параметры `НачалоПериода` виртуальных таблиц оборотов, отсекая исторические расходы. *Урок:* Использовать внутренние параметры `&НачалоВсегоВремени` и `&КонецВсегоВремени` с установленной галочкой «Ограничение доступности» в СКД.
